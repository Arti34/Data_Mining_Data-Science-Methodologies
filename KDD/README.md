1. Open https://colab.research.google.com/.
2. Upload `kdd_project_final.ipynb`.
3. Choose Runtime -> Run all.
4. Confirm that the source says Kaggle, and review the Apriori rule table and manual checks.
5. If you need separate CSV files, download `KDD_artifacts.zip` from the Colab Files pane after the run.
